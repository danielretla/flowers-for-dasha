# Цветочный мини-сайт для Даши 🌸

Интерактивная мобильная открытка, которая открывается по QR-коду.

## Что внутри

- Начальная страница с небольшим шуточным Python-кодом.
- Выбор из 4 оттенков и выращивание 7 цветов одним нажатием.
- Анимация сборки букета и частиц-лепестков (лёгкий Canvas).
- Конверт с персональным посланием, финальный сюрприз, кнопка повтора.
- Необязательные звуковые эффекты (выключены по умолчанию).
- Без трекеров, серверных ключей, фреймворков и обязательных внешних библиотек. Шрифты подгружаются с Google Fonts, но есть системные запасные варианты.

## Как проверить на компьютере

Открой `index.html` двойным щелчком. Сайт работает локально и на мобильном телефоне.

## Как разместить бесплатно через GitHub Pages

1. Создай на github.com **публичный** репозиторий, например `flowers-for-dasha`.
2. Загрузи в корень репозитория `index.html` и `.nojekyll` (Add file → Upload files → Commit changes). Можно также загрузить `README.md`.
3. Открой репозиторий → Settings → Pages.
4. В Build and deployment установи Source: **Deploy from a branch**.
5. Выбери Branch: **main**, Folder: **/(root)**, нажми **Save**.
6. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/flowers-for-dasha/`.
7. Убедись, что сайт открывается в приватном окне браузера, затем сгенерируй QR-код на этот адрес и напечатай на маленькой карточке для букета.

Важно: GitHub Pages публичен. Письмо в `index.html` и история репозитория будут доступны тем, кто найдёт ссылку или репозиторий. Не добавляй в файл секреты и приватные подробности.

## Как изменить имя и текст

Внизу `index.html` найди объект `const CONFIG` и измени `name`, `letter`, `signature`. Сохрани файл и перезагрузи страницу. Имя в терминальном блоке написано отдельно, поэтому при переименовании нужно также заменить текст `"Даша"` в HTML (для одного адресата ничего менять не надо).

**Важно:** текущая верстка рассчитана на **7 цветков** (`flowerCount: 7`). Менять количество без дополнительных координат в `positions` не рекомендуется.

## Как собрать QR

Когда сайт опубликован, пришли мне его точный URL, и я сделаю пригодный для печати QR-код. Код должен вести на опубликованный сайт, а не на `file:///...` на твоём компьютере.
